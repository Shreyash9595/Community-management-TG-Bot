## 📌 Project Overview
This project is an **Enterprise Automation Tool** built to eliminate the "Excel fatigue" faced by operations teams.

Traditionally, reporting required managers to manually open multiple Excel logs, copy-paste data, and email summaries. I engineered a **Python-based ETL (Extract, Transform, Load) Pipeline** that automates this entire workflow. It monitors raw data sources, processes metrics, and delivers instant business intelligence via a Telegram Bot interface.

---

## 💼 Business Impact & Efficiency
* **100% Manual Entry Reduction:** Completely removed the need for human intervention in daily reporting.
* **Real-Time Decision Making:** Stakeholders receive performance metrics (Daily Sales, User Growth) automatically, enabling faster strategic pivots.
* **Scalability:** The script utilizes efficient Pandas vectorization, capable of processing thousands of rows in seconds.

---

## ⚙️ How It Works (The ETL Logic)

### 🔹 Phase 1: Extract (Data Ingestion)
The system uses the `os` and `glob` libraries to monitor a designated directory.
* It identifies the most recent `.xlsx` or `.csv` log file generated by the legacy system.
* It automatically handles file encoding issues to prevent read errors during ingestion.

### 🔹 Phase 2: Transform (Data Processing)
Once the file is loaded, **Pandas** takes over:
* **Cleaning:** Drops rows with missing critical values (`dropna`) and standardizes date formats.
* **Aggregation:** Groups data by "Category" or "Region" to calculate daily totals.
* **Analysis:** Calculates `Day-over-Day (DoD)` growth to provide context (e.g., *"Sales are up 5% from yesterday"*).

### 🔹 Phase 3: Load (Reporting via API)
The processed insights are formatted into a clean HTML/Markdown string.
* The script constructs a payload.
* It sends a `POST` request to the **Telegram Bot API** endpoint (`/sendMessage`).
* It handles API rate limits and connection timeouts using robust `try-except` blocks.

## 🛠️ Configuration & Deployment

### Environment Variables
For security, all sensitive keys are stored in a `.env` file, not the source code.

    TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
    CHAT_ID=-100123456789
    DATA_SOURCE_PATH=/var/www/data/logs/

### Deployment Strategy
The pipeline is deployed on **PythonAnywhere** (Cloud Platform).
* **Always On:** Uses a persistent loop with sleep intervals to ensure 24/7 uptime.
* **Resource Efficiency:** Optimized to run with minimal RAM usage by processing data in chunks.
